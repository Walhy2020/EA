EA 桌面提醒
版本：0.5.0

这个目录用于放分享给同事的输出包。
打包时应包含：
- EA桌面提醒.exe
- desktop-tip-client.ps1
- desktop-tip-updater.ps1
- 启动EA右下角提醒.bat
- config\desktop-tip-client.config.json
- README.md

同事第一次启动无需登录，也无需填写企业微信 UserID；客户端会自动生成并保存唯一 clientId。
分享包默认连接：https://com.veryeazy.com:39200
成功启动并连接 EA 一次后，服务端才会把这台客户端安装实例记录为已登记桌面客户端。
只复制文件但从未启动、或从未成功连上 EA 的客户端，服务端无法知道，不会收到本次全员桌面提醒。
正式服停服更新通知会显示独立面板：倒计时、已停服、已延长、已完成状态会直接显示。
v0.3.0 起支持在线更新：启动时自动检查，运行期间默认每30分钟检查一次，也可右键悬浮按钮选择“检查更新”。
v0.4.1 起修复重复启动导致多个更新提醒窗口的问题；重复双击会唤醒已有客户端，不再创建多个更新弹窗。
v0.5.0 起请直接双击“EA桌面提醒.exe”，不会显示空白控制台，并默认随当前用户登录 Windows 自动启动。
右键蓝色 EA 按钮可关闭或重新开启“开机自动启动”；旧 BAT 仅保留兼容。
v0.4.0 起右键蓝色 EA 悬浮按钮可选择“发送通知”，直接发送普通桌面通知到全部已登记客户端；可选发送到已绑定企业微信群，支持普通通知和 @所有人。
客户端发送当前是临时测试能力，只校验本机 clientId 已登记；后续权限阶段会切换授权发送者机制。
v0.3.4 起通用消息底部唯一“收到”按钮水平居中；仍只显示正文，不显示来源/批次，也不打开URL。
更新会保留本机 config、data、logs 和 clientId。
