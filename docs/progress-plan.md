收件人交互优先使用中文姓名；userid 只作为管理员兜底，不要求普通同事填写。
机器人会保留短期结构化上下文：版本查询后可说“上月呢 / 发送给我 / 也发给某某”；人员任务查询后可说“刘宇呢 / 李猛呢”。
版本统计回复分为标题、内容、结尾三行；Excel 默认发到当前对话，群聊发当前群，单聊发当前同事。
询问“版本计划 / 版本情况 / 当前有几个版本”时默认按本周统计，并直接推送 Excel 到当前对话，不再二次询问。
