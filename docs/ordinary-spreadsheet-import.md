# 企业微信普通表格

版本：EA v0.7.19，M06。

## 使用方法

对1号机器人发送：`创建普通表格，名称叫：项目周报`。

机器人创建空的企业微信普通表格并返回地址。真实发起人加入文档管理员列表，EA 通过自身应用权限创建，沿用既有权限配置，不额外开放外部或匿名访问。

群里使用时需 @1号机器人。明确说“普通表格”才创建普通表格；泛称“创建表格/共享表格”仍沿用原有智能表格默认行为。

## Excel 转换暂停

目前暂不支持 Excel 转换。发送文件、发送原指令“转成普通表格”或“取消表格转换”，均明确提示暂不支持，并提供新建空表格的示例。

- 不下载或解析附件，不等待下一份文件，不创建转换任务或在线文档。
- 模块的 importExcel 入口同样拒绝，状态 ordinarySpreadsheetImport.enabled 固定为 false。
- 不将文件上传、纯文字写入冒充保留原样的普通表格转换。
- 既有文档和历史记录保持不变。解析/导入辅助代码暂保留，但不从机器人或文档模块执行。
- 文件回调继续校验真实身份并对重复消息去重；不记录正文、附件地址或解密密钥。

## 接口与验证

- 新建文档使用 `wedoc/create_doc`，普通表格固定 `doc_type=4`：https://developer.work.weixin.qq.com/document/path/97460
- 回归命令：`npm run test:ordinary-spreadsheet-import`、`npm run test:doc-creator-routing`、`npm run check`、`npm run check:config`。
- 覆盖创建类型、名称、发起人管理权限和链接返回，以及转换停用后无下载、无 API 创建、无任务写盘，普通聊天和创建路由不受影响。
